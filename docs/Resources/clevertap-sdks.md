This page lists CleverTap’s official mobile and web SDKs, server-side libraries, partner integrations, and community-supported projects. 

Our mobile and web SDKs will enable you to quickly integrate CleverTap into your mobile apps and websites. Our server-side libraries make it easier to call the CleverTap API.

* [Android SDK GitHub repo](https://github.com/CleverTap/clevertap-android-sdk)
