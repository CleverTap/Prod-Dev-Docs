## Overview

Postman is a tool that lets you build and test HTTPS requests. We created [a Postman Collection](https://app.getpostman.com/run-collection/07870691c60583eeccfe) that you can use to test making requests to the CleverTap API. Clicking the button below will automatically import our Postman Collection into your Postman app account.

[![Run in Postman](https://run.pstmn.io/button.svg)](https://app.getpostman.com/run-collection/07870691c60583eeccfe)
