# Overview

The Voucher API enables you to fetch voucher codes that users have earned by completing actions such as referrals, purchases, or participating in promotional campaigns. You can use this API to build a Voucher Tray, a section within your app where users can view and redeem their earned vouchers.

For example, in a shopping app, users might receive Flipkart or Amazon vouchers for inviting friends or completing purchases. By integrating the Voucher API, you can programmatically display these codes based on the user's campaign eligibility.

To integrate the Voucher API, refer to [Fetch Voucher API](doc:fetch-voucher).
