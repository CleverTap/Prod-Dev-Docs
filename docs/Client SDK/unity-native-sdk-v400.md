# Oveview

CleverTap provides a [Unity Plugin](https://github.com/CleverTap/clevertap-unity-sdk) that enables app developers to track, segment, and engage users. The plugin includes the Unity Native SDK, which is packaged within the same Unity module and extends support for multiple platforms, including macOS, Windows, Linux, and WebGL.

Use the following guides to get started with integrating the CleverTap Unity Native SDK in your gaming application:
