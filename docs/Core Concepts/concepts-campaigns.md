# Overview

CleverTap offers nine different messaging channels enabling you to create engagement strategies to reach your users with a personalized message at the right time.

For example, you can set up a campaign to send a push notification with a discount code to users who have viewed a certain product.

You can use our Campaigns feature through the [CleverTap dashboard](https://docs.clevertap.com/docs/intro-to-campaigns) or through the [Campaign API Endpoints](doc:campaign-object).
