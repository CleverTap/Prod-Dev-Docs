# July 17

## [Flutter 1.8.0](https://github.com/CleverTap/clevertap-flutter/releases/tag/1.8.0)

### New Feature

- **Added** support for [CleverTap Android SDK v5.1.0](https://github.com/CleverTap/clevertap-android-sdk/blob/master/docs/CTCORECHANGELOG.md#version-510-june-28-2023).
- **Added** support for [CleverTap iOS SDK v5.1.1](https://github.com/CleverTap/clevertap-ios-sdk/blob/master/CHANGELOG.md#version-511-july-13-2023).
- **Added** support for notification click handling when the app is terminated or killed. The CleverTap plugin provides the following two ways to handle user interactions with notifications, depending on whether the app needs to perform UI or non-UI operations:
  - Use `CleverTapPlugin.getAppLaunchNotification()` to perform UI-impacting operations such as redirecting the user to a specific page.
  - Use `CleverTapPlugin.onKilledStateNotificationClicked(_onKilledStateNotificationClickedHandler)` to perform non-UI operations such as performing HTTP requests, IO operations with local storage, and so on. For more information on handling notifications properly, refer to [Notification Click Handling](https://github.com/CleverTap/clevertap-flutter/blob/master/doc/Usage.md#handle-notification-click).
- **Android Platform** 
  - **Added** support for developer-defined default notification channel. For more information about setting up a default channel in your app, refer to the [Usage.md](https://github.com/CleverTap/clevertap-flutter/blob/master/doc/Usage.md#default-notification-channel) file.
    > 📘 Note
    > 
    > This feature is only supported for CleverTap core notifications. Support for push templates will be released soon.

### Fixes

- **iOS Platform**
  - **Fixed** Cocoapods generated duplicate UUIDs warnings.
  - **Mitigated** potential App Inbox errors.
- **Android Platform**
  - **Fixed** [#428](https://github.com/CleverTap/clevertap-android-sdk/issues/428) Race-condition when detecting whether an In-App message should appear.
  - **Fixed** Push primer alert dialog freeze behavior, which became unresponsive when clicked outside the window.
