We are excited to share the May SDK changelog for our product!

> 📘 Note
>
> Click each SDK header to view the corresponding GitHub repository for release details.

# May 28

## [Web 1.7.5](https://github.com/CleverTap/clevertap-web-sdk/releases/tag/v1.7.5)

* Fixes a background color issue with Banner and Carousel templates.

# May 17

## [Web 1.7.4](https://github.com/CleverTap/clevertap-web-sdk/releases/tag/v1.7.4)

* Fixes an issue with the path of the installation script for the Shopify service worker.

# May 10

## [Flutter 2.4.0](https://github.com/CleverTap/clevertap-flutter/releases/tag/2.4.0)

### New Features

* **Web Platform**
  * Adds the `recordChargedEvent` method for the Web.
  ### Bug Fixes
* **Web Platform**
  * Adds [JS package](https://pub.dev/packages/js) dependency to handle the latest versions.
* **Android Platform**
  * Fixes [#114](https://github.com/CleverTap/clevertap-flutter/issues/114). An issue related to callbacks from Native to Dart. This occurs when a third-party plugin like `flutter_workmanager` is used.

# May 6

## [Cordova 3.1.0](https://github.com/CleverTap/clevertap-cordova/releases/tag/3.1.0)

### New Features

* **iOS Platform**
  * Supports [CleverTap iOS SDK v6.2.1](https://github.com/CleverTap/clevertap-ios-sdk/releases/tag/6.2.1).
  * Adds Privacy Manifests for iOS SDK.

### Bug Fixes

* **iOS Platform**
  * Fixes a crash due to out-of-bounds in `NSLocale` implementation.
  * Fixes a bug where client-side In-Apps were not discarded. This bug occurs when the rendering status is set to **discard**.
