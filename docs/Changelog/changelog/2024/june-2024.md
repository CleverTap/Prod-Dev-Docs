We are excited to share the June SDK changelog for our product!

> 📘 Note
> 
> Click each SDK header to view the corresponding GitHub repository for release details.

# June 18

## [Web 1.8.2](https://github.com/CleverTap/clevertap-web-sdk/releases/tag/v1.8.2)

- Fixes an issue in `getLocation` function where the location data was not sent in requests.
- Exposes the `getSDKVersion` method.

# June 14

## [Web 1.8.1](https://github.com/CleverTap/clevertap-web-sdk/releases/tag/v1.8.1)

- Fixes an issue with the Preview of Web Pop-ups related to XSS changes.

# June 12

## [Web 1.8.0](https://github.com/CleverTap/clevertap-web-sdk/releases/tag/v1.8.0)

- Introduces the new template _In Page Customisation_ for the _Web Native Display_ channel.

# June 11

## [Web 1.7.6](https://github.com/CleverTap/clevertap-web-sdk/releases/tag/v1.7.6)

- Adds `sandbox` attribute to iframe specifically for preview purposes. This enhances protection against cross-site scripting (XSS) vulnerabilities.
