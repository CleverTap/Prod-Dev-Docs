# January 15

## [Android 6.0.0](https://github.com/CleverTap/clevertap-android-sdk/releases/tag/corev6.0.0_ptv1.2.2)

* **Added** support for client-side in-apps.
* **Added** support for ExoPlayer `v2.19.1`.
* **Fixed**  no empty message for app inbox without tabs.
* **Removed** `onClickListener` for Image of Cover In-App.

## [Push Templates SDK 1.2.2](https://github.com/CleverTap/clevertap-android-sdk/releases/tag/corev6.0.0_ptv1.2.2)

* Minor changes and improvements.

## [iOS 6.0.0](https://github.com/CleverTap/clevertap-ios-sdk/releases/tag/6.0.0)

* **Added** support for client-side in-apps.
* **Fixed** a bug that prevents the dismissal of certain in-apps.
