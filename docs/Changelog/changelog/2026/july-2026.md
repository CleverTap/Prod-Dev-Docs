# July 28

## [Android 8.4.0](https://github.com/CleverTap/clevertap-android-sdk/blob/master/docs/CHANGELOG.md#version-840)&#x20;

### What's New

- **Split of Clicks**: Adds per-element click attribution to the `Notification Clicked` event across all In-App templates. Each clickable element within an In-App is recorded as its own click event, providing finer-grained analytics for each element. Also adds a configurable swipe-to-dismiss gesture for In-Apps. Dismissals via swipe are tracked as `Notification Clicked` events.

### Enhancements

- Enhances accessibility support across In-App notifications and App Inbox:
  - Dynamic text scaling support.
  - Screen-reader announcements and content descriptions for close buttons, images, and media controls.
  - Dismiss button tap area increased to 48dp.
  - Corrects TalkBack navigation order in carousel templates.

### Bug Fixes

- **App Inbox Empty on Android 6.0 – 10:&#x20;**&#x46;ixes a critical issue where App Inbox messages were never saved on Android 6.0 through Android 10 (API 23 – 29).

* **Crash While Playing Video on Android 6.0:&#x20;**&#x46;ixes an `AbstractMethodError` crash that occurred when a Picture-in-Picture (PIP) In-App notification played a video on Android 6.0 (API 23).&#x20;

## [Push Templates 2.5.0](https://github.com/CleverTap/clevertap-android-sdk/blob/master/docs/CTPUSHTEMPLATESCHANGELOG.md#version-250)

### What's New

- **Five Icons Template**: Adds title and message text support to the `Five Icons` template, and a text-only fallback notification when the template cannot be rendered.
- **Vertical Template**: Adds HTML formatting support for the `line1` and `line2` text fields of the `pt_vertical_image` template.

### Enhancements

- Enhances accessibility for the `Manual Carousel` and `Rating` templates for BIS compliance.

### Bug Fixes

- Fixes icon clipping in the collapsed view of the `Five Icons` template when a title or message is present, by using a shorter icon strip.
- Fixes the chronometer color format and border rendering in the `Timer` template.
- Fixes a crash (`SecurityException`) during the pre-download network check when the host app does not declare the `ACCESS_NETWORK_STATE` permission.

## [CTNotificationContent 1.5.0](https://github.com/CleverTap/CTNotificationContent/releases/tag/1.5.0)&#x20;

### Enhancements

- Adds accessibility identifiers and labels for the following interactive elements:
  - Carousel template buttons.
  - Play/pause button in the Auto Carousel template.
  - Star buttons in the Rating and Product Display template action buttons.

## ​[iOS 7.8.0](https://github.com/CleverTap/clevertap-ios-sdk/releases/tag/7.8.0)

### What's New

- **Split of Clicks**: Adds per-element click attribution to the `Notification Clicked` event across all In-App templates. Each clickable element within an In-App now records its own click event, giving finer-grained analytics per element. Also adds a configurable swipe-to-dismiss gesture for In-Apps. Dismissals via swipe are tracked as `Notification Clicked` events.

### Enhancements

- Enhances accessibility support across In-App notifications and App Inbox, including VoiceOver labels, a larger dismiss-button tap area, and improved image content descriptions, helping apps meet accessibility standards.

### Bug Fixes

- Fixes a bug where server-side InApps were not persisted when an empty array was received.
- Fixes a bug where the AIB In-App did not respect the safe area for full-screen cover In-Apps.
- Fixes a potential crash at `NSKeyedArchiver replaceObject:` that could occur while saving variable diffs.
- Fixes a potential concurrency-related crash during simultaneous `variants` updates.
- Fixes a bug where the `Notification Clicked` event did not include deeplink properties for HTML In-Apps.
- Fixes a bug where In-Apps missed while the app was in the background were not shown when the app returned to the foreground.
