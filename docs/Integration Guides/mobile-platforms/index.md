CleverTap provides [SDKs](doc:clevertap-sdks) that enables app developers to track, segment, and engage their users. 

This section of the CleverTap documentation contains guides how to integrate the CleverTap SDK into your app. We have guides for the following platforms: 

* [Cordova](doc:cordova) 
* [React Native](doc:react-native) 
* [Silverlight](doc:silverlight) 
* [Unity](doc:untity) 
* [WinRT](doc:winrt)
