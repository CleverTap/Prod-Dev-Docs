# Facebook Audiences
Facebook Audiences are a great way to re-engage with users outside of your app or website, via ads on Facebook. 

Refer to this [detailed document](https://docs.clevertap.com/docs/setup-facebook-audiences) that explains how to integrate Facebook Audiences with CleverTap to be able to run marketing campaigns



# Google Adwords
Google Adwords is another leading platform you can use to re-engage with users outside of your app or website via the Google Ads network.

The Google Ads remarketing module under Campaigns on the CleverTap dashboard is easy to set up for all your users or distinct user segments. 

Refer to this detailed [setup guide](https://docs.clevertap.com/docs/setup-google-adwords) to understand how to integrate Google AdWords with CleverTap to be able to run marketing campaigns
