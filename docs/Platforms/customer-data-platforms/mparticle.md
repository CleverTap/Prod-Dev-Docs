[mParticle](https://www.mparticle.com/) is a customer data platform that manages data quality and drives better customer interactions. CleverTap can integrate with mParticle to start receiving data from the application. This requires integrating a CleverTap kit with the mParticle SDK. This section provides information about integrating with mParticle SDK for the following:

- [Android Integration](doc:mparticle-native-android-integration)
- [iOS Integration](doc:mparticle-native-ios-integration)
- [Web Integration](https://developer.clevertap.com/docs/mparticle-web-integration)
