You can download the artifacts for iOS from the [CleverTap iOS Segment](https://github.com/CleverTap/clevertap-segment-ios) page.

For integration, download the [Segment Analytics tools](https://github.com/segmentio/analytics-ios).

# Installation
Analytics is available through [CocoaPods](https://cocoapods.org/). To install it, simply add the following line to your `Podfile`:
[block:code]
{
  "codes": [
    {
      "code": "pod \"Segment-CleverTap\"",
      "language": "text"
    }
  ]
}
[/block]
